抽選の結果そのもの（誰が交渉権を得るか）は、どの演出が出ても全員同じ確率です。

## 演出の一覧と確率

ほとんどの回はリーチまで進みます（約20秒）。まれに（約5%）リーチなしでそのまま止まって決まる「一発決着」もあります。

**評価値バー**：スピン中、画面上部に将棋中継のような形勢バーが出ます。
擬似連（仮停止。止まった人の名前と、評価値がどれだけ上がったかが出ます）やリーチの帯がリーダーを指すたびにバーが動きます。針の宝石は、今いちばん評価値が高い人の色に光ります（互角なら無色）。指された人ほど当たりやすい傾きはありますが、結果が読めすぎないよう、普段は接戦寄りに見せています（たまに大きく傾く回もあります）。
評価値は「互角（〜+400）／有利（+400〜）／優勢（+1000〜）／大優勢（+2000〜）」で表示します。決着前は +2000 が上限で、「詰み」は全回転のときだけ、決着すると「+3000 勝ち」です（3人以上のときは1位と2位の差から出します）。

| 演出 | 指した人が当たっている割合 |
|---|---|
| 擬似連 | 60% |
| リーチの帯（通常） | 70% |
| 金リーチ | 80% |
| ゼブラリーチ | 90% |
| 虹リーチ | 確定（評価値の上では最大 +2000） |

**ステップアップ**：リーチの直前に、歩 → 香 → 桂 → 銀 → 金 → 角 → 飛 → 玉 と駒が並びます。上の駒まで行くほど、次のリーチが熱くなります（誰が勝つかは示しません）。

ほかにも：
- 開幕の「〇〇 ／ 〇チーム競合!!」、**振り駒**（「と」が3枚以上でリーチ信頼度UP、5枚でMAX）、駒群予告、役物
- リーチは、その時点で評価値がいちばん高い人から始まります。途中で帯が別のリーダーへ寝返ったり、金や虹に昇格したりします
- PUSH（たまに。虹は連打）
- 止まり方：リーチ中は、帯が指しているリーダーのマスで針が止まります。そのまま止まればその人、動き出せば隣へ・通過して別の人へ
- **境目フリーズ**：2人の境目ギリギリで止まりかけたところで暗転。どっちに転ぶか…
- **再抽選**：止まったあとフリーズして再始動
- **リーチ中のフリーズ**：暗転からの虹リーチ（確定）
- **全回転**：全部のマスが当選者の名前に変わる確定演出。リーチの途中から全回転になるときは、リーチ中の人とは別の人に逆転で決まります。回すほど出やすくなり（1回目5%、2回目10%…最大60%）、出たら元に戻ります。だいたい5回に1回くらい見られます
