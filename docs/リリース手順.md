# リリース手順（開発用）

本番で使われているページを壊さないよう、修正はまず確認用ページで見てから本番に出します。

| | ファイル | URL |
|---|---|---|
| 本番 | `index.html` | https://kumanohikage.github.io/shogi-draft-roulette-dx/ |
| 確認用 | `dev/index.html` | https://kumanohikage.github.io/shogi-draft-roulette-dx/dev/ |

確認用ページは画面下に「確認用」と出ます。設定（名前・画像）は本番と共有です。

## 1. 修正する

1. `dev/index.html` だけを直す（`index.html` は触らない）
2. コミットして push → 1〜2分で確認用 URL に反映される
3. 確認用 URL で動作を確かめる（OBS のブラウザソースでも見るなら、URL を確認用に差し替える）
   - 演出を選んで回したいときは、URL の末尾に `?preview` を付ける（演出確認モード。勝者と演出を指定でき、抽選はしない）

## 2. 本番に出す

1. `dev/index.html` の `const VERSION = '…'` を上げる
   - 不具合の修正だけ: 3番目を上げる（1.0.0 → 1.0.1）
   - 機能や演出の追加: 2番目を上げる（1.0.1 → 1.1.0）
2. `dev/index.html` を `index.html` にコピーする
3. コミットして push、タグを付けてリリースを作る

```
git add index.html dev/index.html
git commit -m "v1.0.1"
git push
gh release create v1.0.1 --title "v1.0.1" --notes "・変更点を短く"
```

## 3. 不具合報告をもらったら

画面の ⚙ 設定の下に出ているバージョン番号を教えてもらう。
