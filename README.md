# ☗ 将棋ドラフト抽選ルーレットDX ☖

**指名、競合。交渉権の行方は――盤上の駒が決める。**

将棋のドラフト会議で**指名が重複（競合）したとき**に、どのリーダーが交渉権を得るかを決めるルーレットです。
パチンコ風の3D演出と将棋中継さながらの評価値バーで、「誰に決まるか」を最後まで引っ張ります。

▶ **今すぐ回す: https://kumanohikage.github.io/shogi-draft-roulette-dx/**

## 使い方

1. 上のリンクを開く（またはこのリポジトリの `index.html` をブラウザで開く。インターネット接続が必要です）
2. 右上の **⚙ 設定**（または S キー）で入力する。入力欄から離れると自動で保存されます
   - 指名者（重複した棋士の名前）
   - 競合したリーダー（1行に1人・2〜8人）
   - 指名者の画像（任意）：ファイルを選ぶ／ドラッグ／コピーした画像を Ctrl+V。盤の真ん中に丸く表示されます
3. **SPIN!**（Space / Enter・盤をクリックでも回ります）
4. 結果は「〇〇 交渉権確定！」と表示されます

入力した内容はブラウザに保存され、次に開いたときも残ります。

## 抽選について

- 当選者は、競合したリーダーの人数から**全員同じ確率**で1人を選ぶ、普通のルーレットです
- 盤はリーダー名のマスを交互に並べたもので、選ばれたリーダーのマスのどれかに止まります
- 演出は、抽選の結果を見てから選んでいます。結果は変わりません

## 演出

毎回、必ずリーチまで進みます（約20秒）。

**評価値バー**：スピン中、画面上部に将棋中継のような形勢バーが出ます。
宝石（針）・擬似連（×2…）・リーチの帯がリーダーを指すたびにバーが動きます。指された人ほど当たりやすい傾きはありますが、結果が読めすぎないよう、普段は接戦寄りに見せています（たまに大きく傾く回もあります）。
評価値は「互角（〜+400）／有利（+400〜）／優勢（+1000〜）／大優勢（+2000〜）」で表示します。決着前は +2000 が上限で、「詰み」は全回転のときだけ、決着すると「+3000 勝ち」です（3人以上のときは1位と2位の差から出します）。

| 演出 | 指した人が当たっている割合 |
|---|---|
| 宝石・擬似連 | 60% |
| リーチの帯（通常） | 70% |
| 金リーチ | 80% |
| ゼブラリーチ | 90% |
| 虹リーチ | 確定（評価値の上では最大 +2000） |

**ステップアップ**：リーチの直前に、歩 → 香 → 桂 → 銀 → 金 → 角 → 飛 → 玉 と駒が並びます。上の駒まで行くほど、次のリーチが熱くなります（誰が勝つかは示しません）。

ほかにも：
- 開幕の「〇〇 ／ 〇チーム競合!!」、**振り駒**（「と」が3枚以上でリーチ信頼度UP、5枚でMAX）、駒群予告、役物
- リーチ中に帯の色が別のリーダーへ寝返る／金や虹に昇格する
- PUSH（たまに。虹は連打）
- 止まり方：リーチ中に止まっているリーダーのまま決まる／入る／ギリギリ入る／いくつか通過して入る／手前で止まって動く（リーチ中に止まっているリーダーが勝つ確率も、ほかの人と同じです）
- **待った!!**：決まった…と思わせて、別の人へ動く
- **再抽選**：止まったあとフリーズして再始動
- **リーチ中のフリーズ**：暗転からの虹リーチ（確定）
- **全回転**（超レア）：全部のマスが当選者の名前に変わる

## 設定

右上の **⚙ 設定**（S キー）。入力欄から離れたとき・画像や色を変えたときに自動で保存されます。

- 指名者、競合したリーダー（1行に1人・2〜8人）
- 指名者の画像（任意）：ドラッグで位置、スライダー／ホイールで拡大。透過画像の背景色も選べます

## キー

| キー | 動作 |
|---|---|
| Space / Enter | 回す・PUSH・結果を閉じる |
| S | 設定を開く |
| H | ボタン類を隠す（配信画面用） |

## OBS に載せる

| 用途 | URL |
|---|---|
| 横配信（16:9） | https://kumanohikage.github.io/shogi-draft-roulette-dx/?layout=horizontal |
| 縦配信（9:16） | https://kumanohikage.github.io/shogi-draft-roulette-dx/?layout=vertical |

配信用URLは、窓やソースの大きさが半端でも比率が崩れません（余りは黒帯）。末尾に何も付けないURLは画面いっぱいの表示です。

**A. ブラウザソース**

1. ソースを追加 → **ブラウザ** → URL に配信用URLを入れ、幅×高さを **1920×1080**（横）か **1080×1920**（縦）にする
2. ソースを右クリック → **操作** で開いた窓から、設定と SPIN を行う
   - **OBS のブラウザソースは、普段のブラウザとは設定の保存場所が別です。** 名前や画像は「操作」の窓で入れてください
   - 「操作」の窓でファイル選択やドラッグが効かないときは、画像をコピーして設定パネルで **Ctrl+V** で貼り付けられます
   - キーボードを使うときは、窓の中を一度クリックしてから。日本語入力はオフ（半角英数）にしておくと確実です
3. 効果音は OBS の音声ミキサーで、このソース単独で音量を調整できます

**B. ウィンドウキャプチャ**

1. 普段のブラウザでページを開き、右上の **🪟 横窓** / **🪟 縦窓** を押すと、アドレスバーの無い配信用の窓が開きます
2. OBS で **ウィンドウキャプチャ** → その窓を選ぶ

背景を透かしたいときは「OBSグリーンバック」→ OBS でクロマキー。配信画面にボタンを映したくないときは「UIを隠す」（H キー）を使います。スピン中はボタン類が自動で消えます。
